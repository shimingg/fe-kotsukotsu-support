## 公開方法

GitHub Pages の公開元は `main` ブランチの `/`（ルート）です。HTML と CSS を直接配信し、ビルドや外部パッケージのインストールは不要です。`.nojekyll` により Jekyll による変換を無効にしています。

- `index.html`：サポート、よくあるご質問、メール窓口
- `privacy.html`：プライバシーポリシー
- `styles.css`：共通デザイン
- `404.html`：存在しないページへの案内

アクセス解析、広告、フォーム、JavaScript、外部フォントは使用していません。GitHub Pages 自体の情報の取り扱いは、プライバシーポリシーをご参照ください。

## 更新時の確認

App の実際のデータ処理に変更がないか確認し、関連する説明と最終更新日を更新してください。公開前に内部リンク、メールアドレス、狭い画面での読みやすさを確認します。メールのリンクは下書きを開くもので、送信は利用者が行います。
